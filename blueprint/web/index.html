  • monotone_convergent_is_bounded

For any ‘f : ℕ → ℝ‘, if ‘Monotone f‘ and ‘∃ r, Tendsto f atTop (nhds r)‘, then ‘IsBoundedSequence f‘.

Proof ▶

Suppose ‘hf : Monotone f‘ and ‘ha : ∃ r, Tendsto f atTop (nhds r)‘. Let ‘⟨r, hr⟩ := ha‘. Then ‘f n ≤ r‘ for all ‘n‘ by ‘monotone_tendsto_ge hf hr‘, so ‘r‘ is an upper bound, giving ‘BddAbove (Set.range f)‘. Since ‘Monotone f‘, we have ‘f 0 ≤ f n‘ for all ‘n‘, so ‘f 0‘ is a lower bound, giving ‘BddBelow (Set.range f)‘. Hence ‘IsBoundedSequence f‘.
